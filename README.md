# 🚗 ParkPay | Parquímetro Virtual com POO

Aplicação interativa que simula um parquímetro digital. O usuário informa um valor em reais e o sistema calcula automaticamente o tempo de permanência permitido e o troco, quando houver.

Projeto desenvolvido como atividade prática de JavaScript com Programação Orientada a Objetos, seguindo uma estrutura simples, organizada e pronta para publicação no GitHub Pages.

## ✨ Funcionalidades

- Entrada de valor pelo usuário
- Cálculo automático do tempo de permanência
- Cálculo de troco
- Validação de valor mínimo
- Mensagens de erro e sucesso
- Interface responsiva com visual premium

## 💰 Regras de negócio

| Valor inserido | Tempo permitido |
|---|---|
| Menor que R$ 1,00 | Valor insuficiente |
| A partir de R$ 1,00 | 30 minutos |
| A partir de R$ 1,75 | 60 minutos |
| A partir de R$ 3,00 | 120 minutos |

## 🧠 Conceitos aplicados

- HTML5 semântico
- CSS3 com layout responsivo
- JavaScript ES6
- Programação Orientada a Objetos
- Manipulação do DOM
- Validação de formulário
- Separação de responsabilidades entre HTML, CSS e JavaScript
