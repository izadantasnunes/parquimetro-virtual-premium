# 🅿️ Sistema de Parquímetro

Projeto desenvolvido para gerenciamento de estacionamento e controle de vagas.

https://izadantasnunes.github.io/parquimetro-virtual-premium/

## 🚀 Funcionalidades

- Cadastro de veículos
- Controle de entrada e saída
- Cálculo automático do tempo
- Valor total da permanência
- Interface responsiva
- Organização das vagas

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## 📱 Responsivo

Sistema adaptado para:
- Desktop
- Tablet
- Mobile

## 🎯 Objetivo

Criar uma solução simples e moderna para gerenciamento de estacionamento urbano e controle de permanência de veículos.
